# One file, two behaviours, chosen by your Python version
# -------------------------------------------------------
# Every number in docs/PROJECT_REPORT.md was produced by one exact stack, on
# Python 3.14.3. A reader who wants to reproduce them bit for bit needs those
# exact versions -- but they require Python 3.13+, which no hosted notebook
# platform offers yet, and the project has to run on Colab too.
#
# So each package appears twice, with a PEP 508 environment marker. On 3.13 and
# newer pip installs the pinned version; below that it installs the floor. One
# install command works everywhere, and the reproduction guarantee survives
# where it can be kept.
#
# The floors are real, not hopeful: the analysis uses no syntax newer than 3.10
# and no pandas API that changed between 2.2 and 3.0. Results computed below
# 3.13 are not *guaranteed* identical to the published ones, so the Colab
# notebook ends with a drift check that diffs every regenerated results/*.csv
# against the committed copy and names anything that moved.
#
# Two other files exist, and neither duplicates this one:
#   requirements-dev.txt        pytest, for the test suite. Not needed to run
#                               the analysis or the dashboard.
#   dashboard/requirements.txt  the six packages the deployed dashboard needs.
#                               It lives there because Streamlit Community
#                               Cloud looks in the entrypoint's directory
#                               first, and it is deliberately smaller so the
#                               hosted app boots without nbconvert or ipykernel.
